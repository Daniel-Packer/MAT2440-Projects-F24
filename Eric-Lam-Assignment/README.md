Sorting and Searching Grades Project

This project, in Python, uses two basic algorithms Bubble Sort and Linear Search. These will manage and interact with a list of student grades. My main motivation for this project was to revive my Python since it has been a while because i've been focusing on java these days, and also to focus on combining sorting and searching functionality effectively within one program.
Most of the code has been modularized within bubble_sort.py and linear_search.py under the src folder to keep things clean and reusable. I took inspiration from how I do projects in Java, making sure there is clear modularity for easy imports in testing and the main program.

What Each Algorithm Does (from my understanding):
Bubble Sort
Bubble Sort is a straightforward sorting algorithm that works repeatedly, swapping adjacent elements of the list if they are in the wrong order. The process will repeat until the entire list is sorted in ascending order.
Worst time complexity: O(n²)

Linear Search
